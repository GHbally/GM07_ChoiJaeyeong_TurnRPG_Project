## 설명
콘솔 환경에서 작동하는 턴제 RPG입니다.
객체 지향 프로그래밍의 핵심인 캡슐화, 상속, 추상화, 다형성을 활용하여 플레이어, 몬스터, 스킬, 아이템, 상점, 전투 시스템을 분리하여 구현했습니다.
플레이어는 이름을 입력하고 전사, 마법사, 도적 중 하나의 직업을 선택할 수 있습니다. 각 직업 서로 다른 능력치와 스킬을 가집니다.

## 게임 흐름
